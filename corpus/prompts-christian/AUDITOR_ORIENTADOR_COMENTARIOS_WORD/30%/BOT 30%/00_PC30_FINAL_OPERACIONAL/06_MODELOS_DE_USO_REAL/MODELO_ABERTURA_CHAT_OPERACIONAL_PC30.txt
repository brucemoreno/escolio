# MODELO_ABERTURA_CHAT_OPERACIONAL_PC30

## 1. Identificação

Nome do arquivo:

`MODELO_ABERTURA_CHAT_OPERACIONAL_PC30`

Função:

abrir um novo chat limpo para uso operacional do sistema PC30 — auditoria de dissertações e teses com foco nos 30% mais críticos.

Status:

`MODELO_DE_ABERTURA_OPERACIONAL_PC30: GERADO`

Este modelo não gera comentário Word, não consome ID, não libera fonte e não homologa nova versão.

---

# 2. Quando usar este modelo

Usar este modelo quando for iniciar um novo chat para operar o pacote PC30 em caso real, com tese, dissertação, capítulo, seção ou bloco textual.

Este modelo serve para:

1. iniciar o bot assessor PC30;
2. preservar o auditor PC30 homologado;
3. registrar o estado de IDs;
4. preservar BVAA/Drive-first;
5. impedir deriva para cobertura ampla;
6. impedir comentário de todos os parágrafos;
7. preparar o fluxo modular por blocos;
8. criar condições seguras para o auditor PC30 atuar.

---
