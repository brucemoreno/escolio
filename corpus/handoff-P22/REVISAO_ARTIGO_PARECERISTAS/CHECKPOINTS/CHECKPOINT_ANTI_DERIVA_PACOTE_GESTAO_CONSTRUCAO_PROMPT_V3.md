# 10. Ressalva operacional não impeditiva

## 10.1. Ressalva

```text
O pacote de gestão é autocontido para retomar o estado da cadeia, mas não é autocontido para executar auditoria textual exata do prompt v3 completo.
```

## 10.2. Explicação

O pacote contém o histórico, os estados, os erros, as correções e a função de gestão. Isso é suficiente para um terceiro chat continuar o gerenciamento da cadeia.

Porém, se o terceiro chat receber o comando:

```text
COMPARAR_PROMPT_V3_COM_ARQUITETURA_CORRIGIDA
```

ou:

```text
AUDITAR_TEXTO_INTEGRAL_DO_PROMPT_V3
```

ele precisará ter acesso ao conteúdo integral do prompt v3 e/ou da arquitetura corrigida.

## 10.3. Regra corretiva

O terceiro chat deve aplicar a seguinte regra:

```text
Se a tarefa for gestão geral, o pacote basta.

Se a tarefa for comparação textual exata, auditoria de conteúdo integral, verificação linha a linha ou revisão do prompt completo, solicitar/anexar/colar o arquivo correspondente.

Não fingir auditoria textual exata sem acesso ao texto integral.
```

Status:

```text
RESSALVA_NAO_IMPEDITIVA
```
