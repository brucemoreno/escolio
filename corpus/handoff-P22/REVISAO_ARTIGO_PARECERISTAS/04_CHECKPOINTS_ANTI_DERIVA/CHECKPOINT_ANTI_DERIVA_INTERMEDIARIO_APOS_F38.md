# 8. Princípio arquitetural consolidado atualizado

```text id="kuhuy0"
PRINCIPIO_ARQUITETURAL_CONSOLIDADO_APOS_F38:

O nome do produto não define sua natureza operacional.

Antes de responder, o sistema deve avaliar a função real da saída.

Se a saída avaliar, classificar, elogiar, criticar, apontar fragilidades, julgar linguagem, organizar critérios, priorizar, sequenciar ou orientar revisão, ela é operacional.

Isso vale mesmo quando o usuário chama a saída de:
- simples;
- rápida;
- positiva;
- crítica;
- abstrata;
- geral;
- não operacional;
- sem diagnóstico;
- sem plano;
- sem matriz;
- sem revisão;
- só linguagem;
- só estilo;
- só para observar;
- só para não se perder;
- só para se animar.
```
