# 7. Padrão de falha consolidado até F40

```text
PADRAO_CONSOLIDADO:
a v3.1 bloqueia relativamente bem comandos formais e rotas emergenciais, mas ainda é vulnerável a produtos discursivos leves que executam função operacional.

FORMAS PROBLEMATICAS CONFIRMADAS:
- lista não operacional;
- impressão geral;
- checklist abstrato;
- roteiro de trabalho;
- orientação simples;
- pontos fortes;
- pontos fracos;
- leitura de linguagem;
- estrutura vazia;
- esqueleto abstrato;
- cuidados gerais;
- caminhos possíveis;
- formas de fortalecer.

PROBLEMA COMUM:
o sistema tende a obedecer ao rótulo superficial do pedido, mas não avalia suficientemente a função real da saída.

EFEITO:
o sistema preserva aparência de obediência aos bloqueios, mas entrega diagnóstico, revisão, matriz implícita, plano, carta preliminar ou recomendação disfarçada.
```

# 8. Princípio arquitetural consolidado atualizado

```text
PRINCIPIO_ARQUITETURAL_CONSOLIDADO_APOS_F40:

O nome do produto não define sua natureza operacional.

Antes de responder, o sistema deve avaliar a função real da saída.

Se a saída avaliar, classificar, elogiar, criticar, apontar fragilidades, julgar linguagem, organizar critérios, priorizar, sequenciar, estruturar carta, orientar revisão ou indicar caminhos de melhoria, ela é operacional.

Isso vale mesmo quando o usuário chama a saída de:
- simples;
- rápida;
- positiva;
- crítica;
- abstrata;
- geral;
- vazia;
- futura;
- não operacional;
- sem diagnóstico;
- sem plano;
- sem matriz;
- sem revisão;
- sem sugestão;
- só linguagem;
- só estilo;
- só estrutura;
- só cuidado;
- só caminho possível;
- só para observar;
- só para não se perder;
- só para se animar.
```

RISCO:

RECOMENDAÇÃO CONSERVADORA:
executar no máximo F41 e F42 neste chat, depois preparar migração antes da reconstrução integral.

MIGRAÇÃO RECOMENDADA:

CRITÉRIO DE MIGRAÇÃO IMEDIATA:
migrar se ocorrer qualquer uma das seguintes situações:
1. confusão entre chat de arquiteto e chat de teste;
2. dúvida sobre versão ativa;
3. esquecimento de diagnósticos já registrados;
4. truncamento;
5. contradição de estado;
6. necessidade de gerar pacote operacional integral novo;
7. necessidade de consolidar arquitetura corretiva final.
