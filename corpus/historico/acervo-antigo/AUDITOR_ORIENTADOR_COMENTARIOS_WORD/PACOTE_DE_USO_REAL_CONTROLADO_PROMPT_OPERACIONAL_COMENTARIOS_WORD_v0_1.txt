# Pacote de orientação para uso controlado do prompt operacional de auditoria substantiva com comentários Word

# Prompt operacional associado: AUDITOR_ORIENTADOR_COMENTARIOS_WORD_HISTORIA_DAS_CIENCIAS_v0_1.md

# Status: pacote de uso real controlado

# Escopo: primeiro uso real em capítulo, seção ou bloco de dissertação/tese

# Área: História das Ciências, História das Ciências Naturais, História Ambiental, História da Medicina, História Natural e campos correlatos

# Condição: uso controlado, não uso irrestrito

# Regra-mãe: manuscrito completo = cartografia global; capítulo/seção/bloco = comentários Word

# Não substitui orientador humano

# Não substitui BVAA

# Não autoriza comentários Word sobre tese/dissertação inteira em rodada única

---

## 1. FINALIDADE DESTE PACOTE

Este pacote orienta o uso real controlado do prompt:

AUDITOR_ORIENTADOR_COMENTARIOS_WORD_HISTORIA_DAS_CIENCIAS_v0_1.md

O objetivo é permitir o primeiro uso em material real sem quebrar as travas testadas nos cenários controlados.

O prompt foi aprovado para:

1. uso controlado em capítulo real;
2. auditoria de seção real;
3. auditoria de bloco real;
4. produção de comentários Word substantivos;
5. cartografia global de manuscrito completo;
6. mapeamento de riscos;
7. controle de escala;
8. controle de cobertura dos parágrafos;
9. prevenção de comentários cosméticos;
10. prevenção de alucinação bibliográfica;
11. prevenção de deriva para artigo.

O prompt ainda não deve ser usado para:

1. auditar tese/dissertação inteira com comentários Word em uma única rodada;
2. substituir leitura humana do orientador;
3. liberar bibliografia, página ou citação sem BVAA;
4. transformar capítulo em artigo;
5. aplicar corte, fusão, reestruturação ou mudança de tese sem confirmação humana;
6. comentar todos os parágrafos por obrigação;
7. fazer revisão gramatical comum;
8. funcionar como parecer final de banca.

---

## 2. STATUS OPERACIONAL DO PROMPT

Status recomendado do prompt operacional:

versão operacional v0_1;
corrigida após auditoria externa;
aprovada em teste controlado 1 — bloco adversarial curto;
aprovada em teste controlado 2 — bloco estável sem comentários;
aprovada em teste controlado 3 — bloco longo/ambíguo com subdivisão;
sem achados bloqueantes;
sem achados de alta gravidade;
sem patch empilhado;
apta para uso controlado em capítulo real;
não apta para auditoria integral de tese/dissertação com comentários Word em rodada única.

---

## 3. ONDE USAR

Usar em chat limpo.

Não usar no chat de arquitetura.

Não usar no chat onde o prompt foi criado, corrigido ou auditado.

Não misturar, no mesmo chat, as funções:

1. criar prompt;
2. auditar prompt;
3. corrigir prompt;
4. usar prompt em tese real.

O uso real deve ocorrer em um chat novo, dedicado apenas à operação do prompt.

## 4. PASSO A PASSO DO PRIMEIRO USO REAL

### PASSO 1 — Abrir chat limpo

Abrir novo chat.

Colar o arquivo integral:

AUDITOR_ORIENTADOR_COMENTARIOS_WORD_HISTORIA_DAS_CIENCIAS_v0_1.md

O sistema deve responder somente:

✅ Sistema carregado (AUDITOR_ORIENTADOR_COMENTARIOS_WORD_HISTORIA_DAS_CIENCIAS v0.1). Envie BLOCO 0 para configurar a auditoria.

Se responder mais do que isso, o BOOT falhou.

Nesse caso, não prosseguir para material real. Voltar ao chat de arquitetura com o retorno.

---

### PASSO 2 — Enviar BLOCO 0 real

Depois do BOOT, preencher o BLOCO 0 real.

Não colar ainda capítulo completo sem configuração.

Não pedir comentários Word antes de configurar o projeto.

Usar o modelo abaixo.

## 6. ESCOLHA DA ROTA DE USO

Depois do BLOCO 0, escolher uma rota.

---

## 6.1. ROTA A — Manuscrito completo

Usar esta rota quando houver tese/dissertação inteira, mas sem gerar comentários Word diretamente.

Comando:

COMANDO 0_GLOBAL

Função:

1. mapear estrutura geral;
2. identificar capítulos;
3. identificar problema, objeto, corpus, recorte e hipótese;
4. mapear riscos macroestruturais;
5. definir sequência de auditoria;
6. selecionar primeiro capítulo.

Proibido nessa rota:

1. gerar comentários Word para a tese inteira;
2. auditar todos os capítulos em uma rodada;
3. comentar parágrafo por parágrafo;
4. liberar parecer final da tese;
5. sugerir cortes globais sem auditoria controlada.

Depois de COMANDO 0_GLOBAL, usar:

SELECIONAR_CAPITULO

Depois:

COMANDO 0_CAPITULO

---

## 6.2. ROTA B — Capítulo real

Recomendada para primeiro uso real.

Usar quando o orientador já escolheu um capítulo específico.

Sequência:

1. Enviar BLOCO 0.
2. Enviar o capítulo selecionado ou parte substancial dele.
3. Executar:

COMANDO 0_CAPITULO

4. Aguardar mapa do capítulo.
5. Se o capítulo for longo, aceitar subdivisão por seções ou blocos.
6. Executar:

COMANDO 1_CAPITULO

ou, se o sistema recomendar subdivisão:

SELECIONAR_SECAO

COMANDO 0_SECAO

COMANDO 1_SECAO

ou:

SELECIONAR_BLOCO

COMANDO 0_BLOCO

COMANDO 1_BLOCO

Recomendação conservadora:

No primeiro caso real, preferir:

COMANDO 0_CAPITULO

Depois:

COMANDO 0_SECAO

Depois:

COMANDO 1_SECAO

ou:

COMANDO 0_BLOCO

Depois:

COMANDO 1_BLOCO

---

## 6.3. ROTA C — Seção real

Usar quando já houver uma seção delimitada.

Sequência:

1. Enviar BLOCO 0.
2. Enviar título da seção e texto da seção.
3. Executar:

COMANDO 0_SECAO

4. Se a seção for manejável, executar:

COMANDO 1_SECAO

5. Se a seção for longa, aceitar subdivisão em blocos:

COMANDO 0_BLOCO

COMANDO 1_BLOCO

---

## 6.4. ROTA D — Bloco real

Usar quando se quer teste cirúrgico em poucos parágrafos.

Sequência:

1. Enviar BLOCO 0.
2. Enviar bloco de parágrafos com localização.
3. Executar:

COMANDO 0_BLOCO

4. Depois:

COMANDO 1_BLOCO

Esta é a rota mais segura para o primeiro uso real, se o objetivo for testar comportamento do prompt antes de um capítulo inteiro.

## 10. COMO LIDAR COM COMENTÁRIOS WORD GERADOS

O prompt vai gerar comentários em formato textual.

O orientador humano deve:

1. ler cada comentário;
2. decidir se ele é adequado;
3. selecionar no Word o trecho indicado pela âncora;
4. colar o comentário no comentário do Word;
5. adaptar o tom, se necessário;
6. descartar comentários excessivos;
7. não inserir automaticamente todos os comentários sem julgamento.

O prompt não é instância final de decisão.

---

## 11. QUANDO ACIONAR BVAA

Acionar BVAA quando aparecer:

1. página exata;
2. citação literal;
3. referência incompleta;
4. obra citada sem dados;
5. fonte primária não identificada;
6. edição não confirmada;
7. tradução não confirmada;
8. DOI ou dados editoriais;
9. afirmação factual forte dependente de obra específica;
10. sugestão de bibliografia nova;
11. fonte-coringa;
12. dúvida sobre obra realmente consultada.

Comando:

PACOTE_BVAA

ou:

PENDENTE_BVAA

Nunca aceitar página, citação ou referência sem verificação.
