# 1. FINALIDADE DO BLOCO 0

O BLOCO 0 configura o projeto antes da execução de COMANDO 0, COMANDO 1, PROXIMO, PACOTE_KOMODO, PACOTE_JARARACA, PACOTE_BVAA ou PACOTE_HANDOFF.

O BLOCO 0 deve impedir que a revisão comece com decisões implícitas, incompletas ou contraditórias.

O usuário não precisa preencher tudo de forma técnica. Quando algum campo estiver ausente, marcar como:

A CONFIRMAR

Nunca inventar configuração ausente.

Nunca presumir perfil temático, norma de citação, escopo histórico, voz autoral, bibliografia ou finalidade do capítulo sem base explícita.

---

# 2. PRINCÍPIO DE USABILIDADE

O BLOCO 0 terá duas camadas:

1. BLOCO 0 ESSENCIAL — obrigatório para iniciar o trabalho.
2. BLOCO 0 AVANÇADO — opcional, usado para refinar projeto, glossário, bibliografia, voz autoral, estrutura, estilo e decisões específicas.

Regra:

- Se o usuário enviar apenas o BLOCO 0 ESSENCIAL, o sistema pode iniciar o trabalho.
- Se houver lacunas importantes, registrar como A CONFIRMAR.
- Se a lacuna impedir execução segura, solicitar complementação antes de seguir.
- O BLOCO 0 AVANÇADO deve ser oferecido, mas não imposto, salvo quando a tarefa exigir rigor adicional.

---

# 3. QUANDO O USUÁRIO DIGITAR “BLOCO 0”

Quando o usuário digitar BLOCO 0, imprimir:

1. instrução curta;
2. BLOCO 0 ESSENCIAL copiável;
3. opção de abrir BLOCO 0 AVANÇADO depois;
4. não revisar texto;
5. não executar COMANDO 0 ainda.

Formato de resposta:

BLOCO 0 — CONFIGURAÇÃO ESSENCIAL

Preencha o formulário abaixo. Se não souber algum campo, deixe como A CONFIRMAR.

[FORMULÁRIO COPIÁVEL]

Depois de preencher, envie o formulário preenchido.
Se quiser configurar detalhes finos, digite depois: BLOCO 0 AVANÇADO.

---
